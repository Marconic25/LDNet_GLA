5. ATTENZIONI SUL CODICE PYTHON
---------------------------------
a) Keras 2.14 vs Keras 3:
   - Il container usa Keras 2.14.
   - Se i pesi .h5 sono stati salvati con Keras 3 (formato layers/dense/vars/0)
     NON sono compatibili. Soluzione: riaddestrare il modello direttamente sul
     cluster così i pesi vengono salvati nel formato giusto.

b) var.value in TensorFlow:
   - In Keras 2.14, var.value è un metodo, non una proprietà.
   - Se il codice usa tape.watch(var.value) o gradient(..., var.value),
     sostituire con tape.watch(var) e gradient(..., var).
   - Fix rapida con sed:
       sed -i 's/tape\.watch(var\.value)/tape.watch(var)/g; \
               s/var\.value for var in self\.variables/var for var in self.variables/g' \
               optimization.py

c) Path relativi:
   - Se lo script usa path relativi (es. ../data/, ../models/), fare sempre
     il cd nella directory giusta prima di lanciare Python:
       bash -c "cd /work/u10677113/progetto/src && python3 script.py"

d) Matplotlib / plot:
   - Sul cluster non c'è display. Usare sempre fig.savefig('output.png')
     invece di plt.show(). Poi scaricare il file con scp:
       scp u10677113@10.78.18.100:/work/u10677113/progetto/src/output.png .

(la quota di /home si esaurisce facilmente con immagini grandi).
